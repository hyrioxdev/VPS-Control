# 🚀 VPS Control
A modern, lightweight, and powerful web-based control panel for managing your Virtual Private Server (VPS). VPS Control provides an intuitive interface for monitoring your server, managing applications, viewing logs, and handling files—all from your browser.

> **⚠️ Project Status:** Open to use.

---

## ✨ Features

* 🖥️ **System Dashboard**
  * Real-time CPU, RAM, Disk, and Network usage
  * Live server statistics
  * Uptime monitoring

* ⚡ **PM2 Management**
  * Start, stop, restart, and reload applications
  * View process status
  * Monitor application performance

* 🌐 **Nginx Management**
  * Manage Nginx configuration
  * Restart and reload Nginx
  * View available sites

* 📁 **File Manager**
  * Upload and download files
  * Create, rename, edit, and delete files
  * Manage folders directly from the dashboard

* 📜 **System Logs**
  * View live system logs
  * Monitor PM2 logs
  * Easily troubleshoot server issues

---

### Requirements
* Ubuntu 22.04+ (Recommended)
* Node.js 18+
* PM2
* Nginx
* Root or sudo access

### Installation
```bash
git clone https://github.com/hyrioxdev/VPS-Control.git
cd vps-control
npm install
npm start
```

---

## 🌐 Accessing the Panel
After installation, open your browser and visit:
```
http://YOUR_SERVER_IP:6100
```
Replace `YOUR_SERVER_IP` with your VPS IP address.
